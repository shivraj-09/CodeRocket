# CodeRocket 🚀

CodeRocket is an educational Android game where players solve puzzles by writing programming commands.

## Features
- Rocket movement using code
- Multiple command execution
- Goal/star system
- Win detection
- Boundary checking

## Tech Stack
- Kotlin
- Android Studio
- XML Layouts

## Example Commands
moveRight()
moveLeft()
moveUp()
moveDown()

## Future Features
